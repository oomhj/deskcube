# 硬件架构规划 v5（纯充电站：24V/6A → 4×SW3518 快充 + INA226 计量 + 0.96" I2C OLED）

> 状态：**架构设计**（配套 `pin_plan.md` §2 的 I2C 引脚推导）
> 产品形态：**桌面充电站（独立设备，无宿主依赖）** = 24V/6A 开关电源 → 保险 → 4×SW3518 快充 + INA226 输入计量；
> WeMos D1 Mini + 0.96" I2C OLED 显示充电数据/时钟/温度，WiFi 对时（NTP）
>
> **v5 相对 v4 的变化（产品定位收窄为"纯充电站"）**：
> 1. 显示屏：ST7789V 240×240（SPI，5 线 + 背光）→ **0.96" I2C OLED**（0 专用引脚，自发光无背光）
> 2. 链路：不再做投屏 → **Go Server / 串口 XOR 帧 / ESP-NOW / JPEG 全部退出本设备**，固件独立重写
> 3. 供电：D1 Mini 由本站 5V buck 供电（5V 脚取电）（独立运行，无宿主 USB 依赖）
> 4. 时钟：WiFi NTP 本地走时（不再依赖宿主送图）
>
> 保留不变：24V/6A 电源（已购）、4×SW3518 模块（已购，每口 5A 保险）、INA226 5mΩ 计量、BME280。

---

## 1. 系统拓扑

```
 24V/6A 开关电源
      │  T8A 慢熔保险
      ▼
 24V→19V 预稳压 buck（待 §4.6 台架实验定案，若 24V 直供通过则砍掉）
      │  19V 母线（≤7.3A）
      ▼
 5mΩ Kelvin 分流 + INA226(0x40) ──► 星形分配 ──┬── SW3518#1 ── USB-C
                                              ├── SW3518#2 ── USB-C
                                              ├── SW3518#3 ── USB-C
                                              └── SW3518#4 ── USB-C

 NodeMCU（ESP-12F，板载 CH340）
   ├─ I2C (GPIO4/5): OLED 0x3C + BME280 0x76 + INA226 0x40
   ├─ WiFi: NTP 对时（可选：天气 HTTP）
   └─ 19V→5V 宽输入 buck ── NodeMCU 5V/VIN
```

- **无宿主机、无串口、无 ESP-NOW、无接收机**。本设备 = 独立桌面充电站。
- 仓库中 Cube（投屏接收机）/Server（Go API）为**独立项目**，与本设备无耦合，继续保留。

## 3. 母线电压决策（v4 结论保留）

模块主开关 **AON7534 V_DS = 30V**。设计准则 V_DS ≥ 1.5×V_in → 19V 安全（1.58×）、24V 越线（1.25×）、TVS 救不了（钳位 39–53V）。

> ⚖ **待台架实验定案（§4.6）**：商品页称"支持 35V 以下、>21V 可出 20V/3A"。若台架通过 → 24V 直供（砍预稳压、开放 20V PD）；任一不过 → 19V 预稳压。本 v5 文档按 19V 母线编写，24V 直供时仅影响 §3/§4/§5/§6 的电压数值（架构不变）。

## 4. 电源架构与保护

### 4.1 功率预算（19V 母线版）

```
24V/6A = 144W ─ 预稳压 96% → 138W (19V, ≤7.3A) ─ 4×SW3518 92% → 127W
4 口平均 ≈ 32W/口；单口独占可打满 45W（24V 直供时 60W）
```

- 固件必须做 **130W 总功率限制**（4 口同时满功率会超 24V/6A 电源）。
- 已购硬件：4 个单口模块，每口自带 5A 输出保险，单口限流 3.3A。
- 单口 45W → 输入 2.6A/模块；输出 5A 保险对 3.3A 限流有 50% 裕量，不误断。

### 4.2 输电与线材

| 段 | 电流 | 线径 | 压降 |
|----|-----:|------|-----:|
| 电源 → 保险 → 预稳压 | ≤6A | 18AWG | ≤0.1V |
| 预稳压 → 分流 → 分配（19V） | ≤7.3A | 18AWG | ≤0.12V |
| 分配 → 每模块 | 均分 ≤1.8A，单模块 ≤2.6A | 20–22AWG | ≤0.1V |

### 4.3 保险丝

| 位置 | 选型 | 作用 |
|------|------|------|
| 24V 总输入 | **T8A / 250V 慢熔** | 短路/起火兜底（8A×24V=192W > 144W，不保护电源，电源靠自身 OCP）；必须慢熔（上电浪涌） |
| 每模块输入 | **不加外部保险**（模块每口自带 5A 输出保险） | 高边 MOS 击穿 → 输出保险熔断隔离该口；低边击穿 → 19V 短 GND 不经输出保险 → PSU OCP 全站断电（换模块恢复）；V2 若要模块级完全隔离再在输入侧加 T5A 慢熔 |
| 19V 母线 | SMBJ20A/22A TVS + 100µF/25V 低 ESR 电解 | 吸收热插拔与线缆反冲 |

### 4.4 预稳压模块选型

| 项 | 要求 |
|----|------|
| 输出 | 19V 固定或可调（18.5–19.5V） |
| 电流 | 持续 ≥8A，推荐 10A |
| 拓扑 | **同步整流、最大占空 ≥90%**（24V→19V = 80–83% 占空，XL4016/MP1584/LM2596 类非同步模块直接否决） |
| 保护 | OCP + OVP + 软启动（软启动顺带抑制 4 模块输入电容浪涌） |
| 现成形式 | "24V 转 19V 10A/20A 降压模块"，¥30–60，带散热片 |
| 实测项 | 满载 7A：输出 ≥18.5V、纹波 ≤100mV、温升 <40°C |

### 4.5 24V 直供 vs 19V 预稳压：10 分钟台架实验（先做这个再买预稳压）

商品页"支持 35V、>21V 可出 20V/3A"与实物 30V 管（7534）的矛盾：参考设计配管恰为 AON6144(40V)+AON7534(30V) 一组 → 30V 管所在 leg 可能不承受完整母线，**直供可能成立**，只能实测：

| # | 测什么 | 判据 |
|---|---|---|
| 1 | 24V 上电 | 正常启动（不启动/反复重启 = OVP<24V → 死刑） |
| 2 | 示波器：模块输入端 + 开关节点，60W 满载/轻载/热插拔 | 峰值 ≤27V 安全，>29V 危险 |
| 3 | PD 握手 20V/3A | 20.0±0.5V 稳定、不掉档 |
| 4 | 输入电解丝印 | ≥35V 与规格相符；25V = 话术 |
| 5 | 60W 连续 30min | 温升/纹波/无重启 |

**全过 → 24V 直供**（省预稳压 ¥45 + 6W 热，开放 20V/3A PD）；**任一不过 → 19V 预稳压**。

## 5. INA226 计量（19V 母线；24V 直供时数值相应变化）

### 5.1 接线

```
 母线 19V ──► IN+ ─[5mΩ 2512 3W]─ IN− ──► 19V 分配节点 ──► 4× SW3518
                 INA226: VB→分流下游母线  VS(V+)→3V3（严禁接母线）  GND→公共地
                         SDA/SCL→I2C 总线
```

### 5.2 分流器

| 参数 | 值 | 依据 |
|------|----|------|
| 阻值 | **5 mΩ / 1% / 3W / 2512** | 19V 侧 7.3A → 37mV / 0.27W；24V 直供 6A → 30mV / 0.18W |
| 量程 | ±81.92mV → ±16.38A | 2 倍余量 |

### 5.3 配置（固件契约）

| 项 | 值 |
|----|----|
| 地址 | **0x40**（A0=A1=GND；0x41–0x43 预留分路计量） |
| 总线电压量程 | **32V**（16.6V 档会截顶） |
| I_LSB | 0.5 mA |
| **Cal** | **2048**（= 0.00512/(0.0005×0.005)；⚠ 旧文档 15812 是错的） |
| 平均/转换 | 平均 16 次、1.1ms → ≈35ms/次 |
| 读取 | **1 Hz**：SHUNT/BUS/CURRENT/POWER/ENERGY；ENERGY 16bit 回绕（65.5Wh≈30min）固件累计 |

### 5.4 读数语义

- `P = V×I` = **模块输入功率**（比手机实收高 ~8–10%）；24V 直供时 = 整站功率。
- 会话判定：`I>150mA` 有负载；空闲 30s → 回落时钟页。
- 基线：上电空闲 5s 采样模块总静态电流（4 路 40–100mA），显示 `I − I_base`。

### 5.5 可选：分路计量（每口独立显示）

**4× INA226（0x40–0x43）** 每路串 5–10mΩ，GPIO 零占用，1Hz 仅 ~1% CPU。
→ OLED 可显示 P1–P4 各口电流（"纯充电站"体验的核心加分项，推荐 V1 直接上）。

## 6. 辅助电源（WeMos D1 Mini 取电）

| 方案 | 峰值损耗（D1 Mini ~0.3A@5V） | 结论 |
|------|--------------------:|------|
| 19V → LDO → 5V | (19−5)×0.3 = **4.2W** | ❌ |
| **19V → 5V buck（1A，宽输入 ≥28V）→ D1 Mini 的 5V 脚** | ~0.25W | ✅ 选定 |

- **必须 5V 脚，不是 3V3 脚**：3V3 是板载 AMS1117 的输出，只能挂 ≤200mA 外设；5V 脚 = CH340 VCC + LDO 输入，不插 USB 独立工作。
- **外设（OLED/BME280/5×INA226）3V3 取自 D1 Mini 的 3V3 脚**：负载 <50mA，板载 1A LDO 裕量充足；要求更稳时加一只 5V→3.3V LDO（MCP1700，¥1）单独供外设。
- **buck 必须宽输入（≥28V）**：预稳压失效直通 24V 时 D1 Mini 存活 → OLED 能显示"母线过压"告警。
- USB 口仅烧录/调试：接 PC 时与站内 buck 共 5V 网络（双 ~5V 并联无碍）。
- **GND 全站共地**（buck = 母线 = INA226 = D1 Mini），计量基准一致。
- strapping：D1 Mini 板载已处理（现有接收机固件已验证），V1 零额外电路；仅 V2 定制 PCB 需 §10 电路。
- 24V 直供定案后：改 24V→5V buck，接法不变。

## 7. 显示：0.96" I2C OLED（0 专用 GPIO）

| 项 | 选型 |
|----|------|
| 面板 | SSD1306 128×64 白/蓝，I2C 地址 **0x3C**（RST 脚悬空） |
| 备选 | 1.3" SSD1322 128×64 **RGB**（0x3D，整帧 3KB≈250ms@100kHz）—— 显示面积 ~34×17mm，更醒目 |
| 刷新 | 1Hz（bit-bang I2C 100kHz，整帧 1KB≈82ms）；不做动画 |
| 字体 | 16px 中文 ×8 行 |
| 烧屏对策 | 空闲 10min → 亮度降 2 档；6h 静态 → 熄屏；夜间熄屏（固件定时） |

**UI 布局（16px，8 行）**：

```
 12:34:56            28.5°C
 总功率 128W   总电流 6.8A
 P1 2.31A      P2 0.00A      ← 无分路计量时：两行合并为总功率条
 P3 0.00A      P4 1.20A
 本次 12.3Wh   累计 1280Wh
 输入 19.0V    状态: 快充×2
 温度 28.5°C   湿度 55%
 (空闲 30s → 大时钟页，6h → 熄屏)
```

**按键（2 个，GPIO0/2 上拉 10k + 按键→GND）**：切换页面 / 亮度 1–10 档（EEPROM 持久化）。
> 纯充电站没有亮度 PWM（OLED 亮度由驱动寄存器 GCON 控制，占 0 GPIO）。

## 8. I2C 总线（唯一外设总线）

| 项 | 规格 |
|----|------|
| 引脚 | **SDA = GPIO4 (D2)，SCL = GPIO5 (D1)**（`pin_plan.md` §2 唯一可行推导；Wire 默认脚，`Wire.begin()` 不传参亦可） |
| 速率 | 100 kHz |
| 上拉 | 4.7k ×2 → 3V3 |
| 地址表 | OLED 0x3C / SSD1322 0x3D、INA226 0x40（分路 0x41–0x43）、BME280 0x76、（V3）DS3231 0x68 |
| 采样纪律 | bit-bang 与 OLED 刷屏避开同窗口：INA226/BME280 各 1Hz，OLED 刷新 1Hz 错峰 |

## 9. 无线 / 时钟（独立运行）

- **NTP**：WiFi（SSID/密码存 NVS/EEPROM），`pool.ntp.org` 或 `ntp.aliyun.com`，每 30min 校准，RTC 无断电记忆。
- **天气（可选）**：ESP8266 直接 HTTP GET（wttr.in / OpenWeather），30min 缓存一行显示；断网不影响核心功能。
- **配网**：首次上电 SoftAP 配网（或 EEPROM 预存）。
- **无串口依赖**：CH340 仅作烧录/调试（NodeMCU 板载），产品运行不接 PC。

## 12. 热设计

| 热源 | 满载损耗 |
|------|--------:|
| 4× SW3518（92%） | ≈11W |
| 24V→19V 预稳压（96%） | ≈6W（24V 直供定案 → 0） |
| 19V→5V buck | ≈0.3W |
| **箱内总热量** | **≈17W**（24V 直供 ≈11W） |

1. 外壳必须通风（下进上出）或金属壳导热；预稳压贴散热片，与 4 模块分开布置
2. 模块间距 ≥10mm
3. **BME280 离模块/预稳压 ≥15mm**（否则温度偏高 2–5°C）
4. OLED 贴屏幕面，不靠近热源（SSD1306 工作温度上限 70°C 表面）

## 15. 固件契约（重写）

1. **I2C**：`Wire.begin(4,5)`（或默认），100kHz；扫描确认 0x3C/0x40/0x41–0x43/0x76。
2. **INA226**：CONFIG = 32V 档 + 平均 16 + 1.1ms；Cal = 2048（5mΩ 实测值复核）；1Hz 读 0x01/0x02/0x04/0x03，ENERGY 回绕累计；分路同参数。
3. **OLED**：U8g2 或 ssd1306 库；16px 中文 8 行；1Hz 刷新；空闲 10min 降亮 / 6h 熄屏（防烧屏）；亮度 1–10 档 EEPROM。
4. **NTP**：WiFi + pool.ntp.org/ntp.aliyun.com，30min 校准；天气 HTTP（可选，30min 缓存）。
5. **总功率限制**：`P_in > 130W` → UI 告警 + 状态灯（屏幕提示"功率受限"）。
6. **基线/会话**：空闲 5s 采样基线；`I>150mA` 判充电会话；空闲 30s 回落时钟页。
7. **母线告警**：`V<17V`（跌落/过载）或 `V>21V`（预稳压异常/直通）→ 告警页。
8. **持久化**：EEPROM 存 SSID/密码、亮度、基线、累计能量（含回绕计数）。
9. **按键**：GPIO0 切页（充电/时钟/设置），GPIO2 亮度 ±。
10. 禁止硬编码母线电压常量（19V/24V 两版切换）。
