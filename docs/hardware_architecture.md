# 硬件架构规划 v4（ESP8266 桌面充电站：24V 输入 → 19V 母线 → 4×现成 SW3518 + INA226 计量 + ESP-NOW 投屏时钟）

> 状态：**架构设计**（配套 `pin_plan.md`；引脚方案 v1→v4 不变，INA226 复用 I2C 总线，**零新增 GPIO**）
> 产品形态：**桌面充电站** = 24V/6A 开关电源 → 8A 保险 → **24V→19V 预稳压** → INA226 计量 → 4 路 SW3518 快充输出；ESP-12F 显示充电状态/时钟/天气
>
> **v4 相对 v3 的唯一实质变化：母线电压由 24V 降到 19V（插入一级 24V→19V/10A 降压模块）。**
> 原因：已确认现成模块主开关是 **AON7534（V_DS = 30V）**，24V 下只有 1.25× 余量（准则要求 ≥1.5×），且模块**不做更换** → 只能降母线。
> 另修正 v2 的两个错误：INA226 的 **Cal 应为 2048**（非 15812）、**VS 必须接 3V3**（不能接母线）。

## 2. 单设备硬件框图（基站）

```

      │  (18AWG，≤1m)
      ▼
 ┌──────────┐
 │ T8A 慢熔  │  ← 短路兜底（见 §4.3）
 └────┬─────┘
      ▼
 ┌───────────────────────┐
 │ 24V→19V / ≥10A 预稳压   │  ← 关键新增级（§4.5）
 │ 同步降压模块 (~96%)     │     软启动顺带抑制后级浪涌
 └──────────┬────────────┘
            ▼  19V 母线
 ┌────────────────────┐
 │ 5mΩ 2512 Kelvin 分流│────────┬────────┬────────┬────────┐
 │  INA226 (0x40)     │        ▼        ▼        ▼        ▼
 │  VB→分流下游 19V   │
 │  VS→3V3            │     SW3518#1  SW3518#2  SW3518#3  SW3518#4
 └────────────────────┘     (每口自带 5A 保险，输入侧不加外部保险)
                             ▼        ▼        ▼        ▼
                          USB-C/A ×4 (PD/QC/PPS, 单口 ≤15V/45W)

  辅助电源: 19V ──[19V→5V buck]── 5V ──[LDO]── 3V3 ── ESP-12F / 屏 / BME280 / INA226
  背光:   5V ── LED ── NPN(S8050, 基极=GPIO12+1k, 基极下拉10k)  [active HIGH]
```

**要点**
1. **24V 不直接进模块** —— 这是 v4 的核心修正。
2. **INA226 放在预稳压之后**（19V 母线）：读数 = 4 路模块真实总输入电流/功率，语义最干净。
3. 分流下游星形分到 4 模块；**分路保护由模块自带每口 5A 保险承担，输入侧不加外部保险**（故障隔离范围见 §4.3）。
4. ESP/屏/传感器走独立 19V→5V→3V3 支路，不经过分流器。

## 3. 母线电压决策（本方案的关键，先说结论）

### 3.1 为什么必须是 19V（而不是 24V）

模块主开关 **AON7534 的 V_DS = 30V**（DFN3x3，26–30A）。开关节点电压 = V_in + 漏感振铃，设计准则 **V_DS ≥ 1.5 × V_in**：

| 母线 | 30V MOS 比值 | 判定 | 对应最高 PD |
|-----:|:---:|------|------|
| 12V（车充原场景） | 2.5× | ✅ 舒适 | 20V（需 40V 辅助管） |
| **19V（本方案）** | **1.58×** | ✅ 达标（19–20V 输入 + 30V MOS 是行业标准组合，笔记本适配器同款） | ~15V / 45W |
| 20V | 1.50× | ⚠ 刚好卡线 | ~15V / 45W |
| **24V（v3 方案）** | **1.25×** | ❌ 振铃即 29–34V，越界 | — |
| 26V | 1.15× | ❌ | — |

**TVS 救不了**：standoff ≥24V 的 TVS（SMBJ24A/SMBJ33A）钳位电压都在 39–53V，对 30V 管子形同虚设。**唯一可行的方向就是降母线**。

同时检查**模块输入电容耐压**：原厂参考设计明确要求输入电容 ≥35V（建议 50V）。若现成模块用的是 25V 电解，24V 下已到 96% 额定（电解寿命急剧下降），**19V 下是 76%，安全**。

### 3.2 降母线的代价

| 代价 | 说明 |
|------|------|
| 无法 20V PD | 降压拓扑要求 V_in > V_out，19V 输入最多输出 ~15V（45W）或 PPS 11V/5A；**笔记本 65W（20V）充不了** |
| 多一级转换 | ~4% 损耗 + ~6W 热（见 §4.5） |

> 如果确定**要充 20V PD 笔记本**：只能换 40V MOS 的模块（或用原厂参考设计板），那就回到 24V 母线。现成 AON7534 模块做不到。

## 4. 电源架构与保护

### 4.1 功率预算（19V 母线）

```
24V/6A = 144 W
  └─ 24V→19V 预稳压 96%  → 138 W (19V 母线, ≤7.3A)
       └─ 4×SW3518 92%    → 127 W
            └─ 4 路平均 ≈ 32 W/路
```

| 输入电源 | 预稳压后母线 | 模块可输出 | 4 路平均 | 备注 |
|---------|-----------:|----------:|--------:|------|
| **24V/6A（当前）** | 19V / 138W | 127 W | **32 W** | 4 台手机同时快充够用 |
| 24V/8A | 19V / 184W | 169 W | 42 W | 需换电源 |
| 24V/10A | 19V / 230W | 212 W | 53 W | 电源 + 预稳压模块都要升级 |

**现实体验**：4 台手机同时快充 → 每台 ≈30W 档（9V/3A 或 15V/2A），够用；单台独占 → 可拿满 45W。
**固件必须做总功率限制（约 130W）**：否则 4 台同时要满功率会让 24V/6A 电源过载掉压。

> ⚠ **已定硬件**：4 个单口模块（每口自带 5A 输出保险），单口限流 3.3A。
> ⚠ **单口 45W 在 19V 母线可打满**：15V/3A = 45W → 输入电流 45/0.92/19 ≈ **2.6A/模块**；输出 5A 保险对 3.3A 限流有 50% 裕量，不会误断。
> 模块自身功率上限提醒：SW3518S 默认只开放 **60W（20V/3A）**，100W 需原厂定制固件；19V 母线下单口上限实际为 15V/3A = 45W。

### 4.2 输电与线材

| 段 | 电流 | 线径 | 压降 |
|----|-----:|------|-----:|
| 电源 → 保险 → 预稳压 | ≤6 A | 18AWG (0.75mm²) | ≤0.1 V @1m |
| 预稳压 → 分流 → 分配节点（19V） | ≤7.3 A | 18AWG | ≤0.12 V |
| 分配节点 → 每个模块 | 均分 ≤1.8A，**单模块可达 2.6A**（单口 45W） | 20–22AWG | ≤0.1 V |
| 分配形式 | — | 端子排或铜排，**星形**，禁止菊花链 | — |

### 4.3 保险丝

| 位置 | 选型 | 作用 |
|------|------|------|
| 24V 总输入 | **T8A / 250V 慢熔**（按你指定） | 短路/起火兜底。注意 8A×24V=192W > 电源 144W → **它不保护电源**，电源靠自身 OCP。若想顺带保护预稳压模块，可换 **T6.3A** |
| 必须慢熔（T） | — | 预稳压 + 4 模块输入电容上电浪涌很大，快熔会秒断 |
| 每模块输入 | **不加外部保险**（模块每口自带 5A 输出保险） | 输出保险串在故障回路里：模块**高边 MOS 击穿** → 19V 经短路打到输出 → 5A 保险熔断，隔离该口；**低边 MOS 击穿** → 19V 直接短到 GND，不经过输出保险 → 靠 PSU OCP 全站断电（换模块恢复）。若 V2 要求"单模块故障不拖全站"，再在输入侧加 T5A 慢熔 |
| 19V 母线 | **SMBJ20A/22A TVS + 100µF/25V 低 ESR 电解** | 吸收热插拔与线缆反冲（母线已降到 19V，用 25V 电容即可；若模块输入电容 35V 更佳） |

### 4.4 为什么用"降母线"而不是"换 MOS / 换模块"

| 方案 | 结论 |
|------|------|
| 换 40V MOS（AON6144/CSD18512Q5B + AON7140/RH6G040CG） | ❌ 4 模块 × 4 管 = 16 颗，风枪返修，**按你的要求不动现成板子** |
| 买原生 40V 模块 | ❌ 同上，板子已定 |
| **加一级 24V→19V 预稳压** | ✅ **选定**：只增加一个现成模块，零返修 |

> ❌ 顺带避坑：搜"AON7534 替代"会推 **AON7406 / AON7408 / AON7400A**，这三颗 datasheet 的 BVDSS 都是 **30V**（网上答案有误，已逐份核对）。虽然本方案不需要换管，但记录下来避免以后被误导。

### 4.5 预稳压模块选型（关键新增件）

| 项 | 要求 | 说明 |
|----|------|------|
| 输入 | 24V（范围内 18–30V） | — |
| 输出 | **19V 固定或可调**（18.5–19.5V 区间） | 选 19V 而非 20V：MOS 余量 1.58× vs 1.50× |
| 电流 | **持续 ≥8A，推荐 10A**（≥190W） | 24V/6A 满功率时 19V 侧电流 = 144×0.96/19 ≈ **7.3A** |
| 拓扑 | **同步整流**（效率 ≥95%） | 非同步（如 XL4016 类）在 4V 压差、7A 下发热大、效率低 |
| 保护 | 过流/过温/短路（**OCP + OVP**），最好带软启动 | **软启动顺带解决 4 模块输入电容的浪涌问题**；OVP 用于失效直通场景（§17） |
| **占空比** | **同步整流、最大占空 ≥90%、10A 连续** | 24V→19V = **80–83% 占空**：XL4016/MP1584/LM2596 类非同步模块做不到（最小关断时间/最大占空不足），7A 下掉压、效率掉到 ~92%、发烫 → 直接否决 |
| 形式 | 现成 DC-DC 降压模块（"24V 转 19V 10A/20A 降压模块"类，¥30–60） | 需带散热片；满载温升实测 <40°C |

**实测项**：满载 7A 时输出纹波 ≤100mV、模块表面温度、24V 输入侧效率。

> 若你其实**可以换电源砖**：直接买 **19V/9.23A（180W，Dell 类）** 或 **20V/10A** 适配器直供，可省掉这一级（更多功率、更少热、更少故障点，¥60–100）。这是更优解，只是不再使用现有 24V/6A 电源。

### 4.6 ⚖ 待决策：24V 直供 vs 19V 预稳压（10 分钟台架实验定案）

**商品页规格**："支持 35V 以下；供电 >21V 时可输出 20V/3A（60W）" —— 与 SW3518 官方参考设计一致（建议 21–36V）。若属实，**24V 可直供，预稳压级可整级砍掉**，且 20V PD 开放。

**矛盾点**：实物确认主开关含 **AON7534（30V）**。35V 输入设计 + 30V 管并存的两种解释：
- 拓扑允许：3518S 双口 4 管分两组，官方参考设计的推荐配管恰为 **AON6144(40V) + AON7534(30V) 一组** —— 30V 管所在 leg 若不承受完整母线，24V 可能安全；
- BOM 缩水：规格抄芯片手册，管子按 12V 车充级配。

**实验（1 块模块 + 24V 电源 + 负载 + 示波器）**：

| # | 测什么 | 判据 |
|---|---|---|
| 1 | 24V 上电 | 正常工作（不启动/反复重启 = 输入 OVP<24V → 死刑） |
| 2 | 示波器：模块输入端 + 开关节点，60W 满载/轻载/热插拔 | 峰值 ≤27V 安全；>29V 危险 |
| 3 | PD 握手 20V/3A | 实际 20.0±0.5V、电流稳、不掉档 |
| 4 | 输入电解电容丝印 | ≥35V 与规格相符；25V = 话术 |
| 5 | 60W 连续 30min | 温升/纹波/无重启 |

**分支**：
- **全过 → 24V 直供**：砍预稳压（省 ¥45 + 6W 热）；20V/3A PD 开放；INA226 回 24V 母线（32V 档、5mΩ、Cal=2048 不变）；辅助电源 24V→5V/3V3；功率预算回到 144W→4×33W、单口独占 60W。
- **任一不过 → 19V 预稳压**（§4.5 方案保持）。

## 5. INA226 计量设计（19V 母线，高压侧）

### 5.1 接线（注意：VS 走 3V3，VB 走母线，二者独立）

```
 预稳压输出 19V ──► IN+ ─[5mΩ 2512 3W]─ IN− ──► 19V 分配节点 ──► 4× SW3518
                        │                 │
                        └─ INA226 差分采样 ┘
                            VB  ──► 19V 分配节点（分流下游）
                            VS(V+) ──► 3V3（芯片供电，**严禁接母线**）
                            GND ──► 公共地
                            SDA/SCL ──► I2C 总线（与 BME280 共用）
                            ALERT ──► 可选 GPIO16（默认不接，轮询即可）
```

| 引脚 | 接法 | 说明 |
|------|------|------|
| IN+ / IN− | 分流器两端（**Kelvin 四线**） | 共模 19V，在 INA226 的 0–36V 输入范围内 ✅ |
| VB | 分流**下游** 19V 节点 | 独立于 VS，可 0–36V |
| VS (V+) | **3V3** | 2.7–5.5V 供电；与母线电压无时序要求（datasheet 明确） |

> ⚠ v2/v3 文档里"INA226 V+ 接 5V/24V 节点"的表述混淆了 **VS（芯片供电）** 与 **VB（母线采样）**。**INA226 绝不可由母线供电。**

### 5.2 分流器选型

| 参数 | 值 | 依据 |
|------|----|------|
| 阻值 | **5 mΩ / 1% / 3W / 2512** | 19V 侧最大 7.3A → 压降 **37 mV**、发热 **0.27 W** |
| 量程 | ±81.92 mV → 5mΩ 对应 ±16.38 A | 覆盖 7.3A 两倍以上 |
| 温漂 | 1% + ~±100ppm/°C | 0.27W 自热 <10°C → 漂移可忽略 |
| 布局 | 紧邻预稳压输出端子 | Kelvin 感线从焊盘内侧引出，远离开关节点 |

### 5.3 INA226 配置（固件契约，**修正 v2 的 Cal 错误**）

| 配置项 | 值 | 备注 |
|--------|-----|------|
| I2C 地址 | **0x40**（A0=A1=GND） | 0x41–0x43 预留给分路计量 |
| 总线电压量程 | **32 V**（LSB 1.25mV） | 19V > 16.6V 档，**必须 32V**；16.6V 档会截顶报 16.6V |
| 分流量程 | ±81.92 mV | 固定 |
| I_LSB | **0.5 mA** | — |
| **Cal 寄存器** | **`0.00512 / (I_LSB × R) = 0.00512 / (0.0005 × 0.005) = 2048`** | 整数，无舍入误差 |
| 电流满量程 | 32768 × 0.5mA = 16.38 A（受分流限制） | 7.3A 时约 14600 counts |
| Power LSB | 25 × I_LSB = **12.5 mW** | — |
| 平均/转换 | 平均 16 次，VBUS/VSH 各 1.1ms → ≈35ms/次 | 平滑开关纹波 |
| 读取频率 | **1 Hz**：SHUNT(0x01)/BUS(0x02)/CURRENT(0x04)/POWER(0x03)/ENERGY(0x05) | ENERGY 内部 mWh 累加，注意 16bit 回绕 |
| 精度目标 | 与钳表偏差 ≤2% | V1 验收 |

> ❌ v2 文档的 `Cal = 15812` 是错的（误把 `0.4048` 当常数）。TI 公式：`CAL = 0.00512 / (Current_LSB × R_SHUNT)`。换实测阻值时按公式重算。

### 5.4 读数语义与显示

- `V_bus`：19V 母线（正常 18.5–19.5V；**<17V 说明电源跌落/过载**，>21V 报警）。
- `I`：4 路模块总输入电流（19V 侧）。
- `P = V×I`：**模块输入功率**（比手机实收高约 8–10%）。注意它**不含预稳压的 ~6W 损耗** —— 整站实际从 24V 电源取的电 ≈ 显示值 + 6W。
- ENERGY：累计**输入**能量；与手机侧电量增长交叉验证时预期高约 8–10%。
- 会话判定：`I > 150mA` 表示有负载；连续 30s 低于阈值 → 空闲，屏幕回落时钟/天气页。
- 基线：上电空闲 5s 采样模块总静态电流（4 路约 40–100mA），显示 `I − I_base`。

### 5.5 可选：分路计量（V3 增强）

| 方案 | 器件 | I2C | 成本 | 说明 |
|------|------|-----|-----:|------|
| A | **4× INA226**（0x40–0x43），每路串 5–10mΩ | 单总线可挂 | ≈¥24 | 推荐；GPIO 零占用，1Hz 读取仅占 ~1% CPU |
| B | INA3221（3 通道） | 单总线 | ≈¥12 | 3 路不够，需 2 片 |
| C | 读 SW3518 自身 IIC 状态寄存器 | 地址可能冲突 | 0 | **寄存器定义不公开**，不建议 |

## 6. 辅助电源（母线降到 19V 后仍**必须用 buck**）

| 方案 | 峰值损耗（3V3@290mA） | 结论 |
|------|--------------------:|------|
| 19V → LDO → 3V3 | (19−3.3)×0.29 = **4.6 W** | ❌ 不可行 |
| **19V → 5V buck → LDO → 3V3** | buck ~0.2W + LDO 0.49W = **0.7 W** | ✅ 推荐 |
| **19V → 3V3 buck（1A）直供** | ~0.3 W | ✅ 更简洁（INA226/BME280 对电源噪声不敏感） |

- 背光走 **5V 侧独立 NPN 驱动**，与 ESP 共用同一只 19V→5V buck（NodeMCU 的 3V3 由板载 LDO 产生）。
- **基站供电决策**：NodeMCU 的 5V/VIN 脚接本站 19V→5V buck，**不由宿主 USB 供电** —— 宿主机关机/拔线时基站继续工作（充电计量不停）；屏幕回落到本地充电页（整帧 JPEG/天气页需宿主送图，离线时不可用，属预期行为）。
- **19V→5V buck 必须宽输入（≥28V）**：预稳压失效直通 24V 时该支路仍能工作 → 计量与屏幕存活，能显示"母线过压"告警，便于定位故障。

## 7. 背光驱动

```
  5V ── LEDA ── LED ── LEDK ── C
  GPIO12 ─[1k]─ B   NPN (S8050)     E ── GND
            └[10k]─ GND（基极下拉，复位钳低 → MTDI 安全）
```

- **active HIGH**（固件 `TFT_BACKLIGHT_ON HIGH`，档位映射同步翻转）。
- PWM `analogWrite(12, duty)`，5%~100% 占空，1~10 档存 EEPROM。
- 推导与复位电平验证见 `pin_plan.md` §3。

## 8. I2C 总线

| 项 | 规格 |
|----|------|
| 引脚 | SDA = GPIO4 (D2)，SCL = GPIO5 (D1)（唯一可行组合，见 `pin_plan.md` §2） |
| 速率 | 100 kHz（4×INA226 时可提 400kHz） |
| 上拉 | 4.7k × 2 → 3V3（必须） |
| 地址表 | INA226 @ 0x40、BME280 @ 0x76、（V3）DS3231 @ 0x68、分路 INA226 @ 0x41–0x43 |
| 采样纪律 | bit-bang 与刷屏争 CPU：BME280 ≥1s、INA226 1Hz，避开 `pushImage` 大帧窗口 |

## 9. 串口 / USB 链路

CH340N/CP2102N，115200，TX↔RX 交叉。协议可在重写时演进，硬件仅 TX/RX+GND。

## 10. ESP-NOW 无线电

- channel 1；基站单播 peer ≤5，超了改广播。
- 240×240 JPEG ≈6–8KB ≈30 包，0.3–1s 完成 → 2s 刷图裕量 2–5×。
- 充电状态帧（几十字节）走 ESP-NOW 推送可把刷新提到 1s。
- 天线净空 ≥5mm；**4 个 SW3518 + 预稳压 = 5 个开关噪声源** → 天线远离它们与 19V 分配节点，屏排线与天线走线垂直。

## 13. 热设计

| 热源 | 满载损耗 | 说明 |
|------|--------:|------|
| 4× SW3518（92%） | ≈11 W | 单模块 ~2.8W |
| **24V→19V 预稳压（96%）** | **≈6 W** | 需散热片 + 通风 |
| 19V→5V/3V3 buck | ≈0.5 W | — |
| 背光 | 0.3 W | — |
| **箱内总热量** | **≈18 W** | 比 v3 更热，通风是硬要求 |

要求：
1. 外壳**必须有通风开口**（下进上出）或金属壳导热；预稳压模块与 4 个充电模块分开布置；
2. 模块间距 ≥10mm，预稳压模块贴散热片；
3. **BME280 离模块/预稳压/LDO ≥15mm**（否则温度读数高 2–5°C）；
4. 分流器 0.27W 无需散热，但不要贴 BME280。

## 16. 固件契约（重写代码时的硬件约定）

沿用 v1（背光 active HIGH、`Wire.begin(4,5)`、`tft.init()`→背光→I2C 顺序），新增：

1. **INA226 @ 0x40**：CONFIG = 32V 档 + 平均 16 + 1.1ms；**Cal = 2048**（I_LSB 0.5mA，R=5mΩ）；1Hz 读 0x01/0x02/0x04/0x03，ENERGY(0x05) 回绕累计。
2. **母线电压告警**：`V < 17V`（电源跌落/过载）或 `V > 21V`（预稳压异常）→ 屏幕提示。
3. **总输入功率限制**：`P_in > 130W` 进入限流策略（UI 提示 + 限制并发快充路数），防止 24V/6A 电源过载。
4. 基线扣除 + 会话判定（`I>150mA`，空闲 30s 回落时钟页）。
5. UI：充电页显示 `19V 母线电压 / 总电流 / 总功率 / 本次能量 / 累计能量`。
6. 母线电压窗口按 19V 命名（禁止硬编码 24V/5V 常量）。

## 17. 风险登记

| 风险 | 触发条件 | 影响 | 缓解 |
|------|---------|------|------|
| ~~24V 打 30V MOS~~ | ~~模块 AON7534~~ | — | ✅ **已消除**：母线降到 19V（1.58×） |
| 模块输入电容只有 25V | 现成模块 BOM 缩水 | 24V 下寿命骤降 | 已降到 19V（76% 额定）；实施前**目视确认电容耐压**，<25V 立即换电容 |

| 箱内 18W 积热 | 密闭外壳 | 模块降额、读数漂移 | §13 通风/间距/散热片 |
